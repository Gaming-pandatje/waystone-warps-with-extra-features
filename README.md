I added Bedrock support for geyser servers.
bedrock players get a special naming ui instead of the anvil ui.

I added a co-owner menu (emerald icon). This menu allows you to give other players permission to edit your waystone (except breaking it and adding co-owners).

## new Permissions

| Permission Node                          | Description |
|------------------------------------------|-------------|
| `waystonewarps.assign_group`         | permission for players to change the group of a waystone|

## new commands

| commands                  | Description |
|-----------------------------------|-------------|
| `/warpdefaultgroup none or groupname`        | sets the default group. every new waystone wil be assigned to this group. |
